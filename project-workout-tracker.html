Workout Tracker

A workout tracker for resistance band and weighted vest training, built around how I actually train.

Live Demo Source Code

About the project

Add an exercise with reps, load and a note for next time, mark it done, and see how many are left. The equipment reference table collapses when you don't need it, and everything is stored in the browser.

Built with vanilla JavaScript, no frameworks or libraries.

Challenges

  • Data that doesn't fit a number

    Load can be a weighted vest measured in kilograms or a resistance band identified by colour. Forcing both into a numeric field would have meant either losing the band colours or inventing fake weights. The field stays a string — it's displayed, not calculated — and only reps are numeric, because those are the ones worth summing.

  • A metric that meant nothing

    The original plan included a total reps counter. Ten pull-ups plus twenty-two bends is thirty-two of what, exactly? Different exercises, different muscles, different loads. I dropped it and kept the one number that answers a real question during a session: how many exercises are left.

  • Letting HTML do the work

    The equipment table is only needed occasionally, so it had to collapse. Instead of writing a toggle in JavaScript, the whole table sits inside a <details> element — the browser handles opening, closing, keyboard support and screen reader announcements for free.
